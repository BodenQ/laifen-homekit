## 已有实物控制依据

本公开版从已实测本地驱动整理：整灯开关、上下灯独立开关和亮度、两路共同色温、Apple 自适应照明、自动亮度暂停/恢复均有原研究灯的设备状态和用户实体反馈。Siri“台灯”总开关以及下灯关闭后不再渐亮均经实体确认。

公开版的主要差别是参数化设备身份、终端安装/连接向导、已有 Homebridge 接入和脱敏发布。没有第二台灯或第二台 Mac，因此不把合成身份测试、状态预检或 CI 通过描述为跨所有设备实测。

持续集成在 macOS / Ubuntu 运行离线测试。Linux CI 通过仅说明相关代码/依赖可运行，不证明 Linux 蓝牙、Docker 或真实 HomeKit 网络发现已验证。
