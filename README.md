# 徕芬大路灯接入 Apple 家庭 / Siri

让电脑通过蓝牙控制徕芬大路灯，在 Apple「家庭」中使用开关、亮度、色温和自适应照明。**本地运行，不需要 Codex、厂商云账号或一直打开徕芬 App。** 非官方项目。

目前仅实测一台 **LFFL01-P + Mac**。其他同型号固件需验证；Linux 为实验性支持，Windows 暂不支持。[兼容性详情](docs/compatibility.md)

## 你需要准备

- 一台常开、位于灯具蓝牙范围内的 Mac，与 iPhone 位于能相互发现的局域网。
- 安装独立的 [Node.js 24 LTS](https://nodejs.org/en/download) 和 [Python 3.12](https://www.python.org/downloads/)（最低 3.11）。终端执行 `node --version`、`python3 --version` 应能看到版本。
- 灯保持通电；从 iPhone 后台划掉徕芬 App，避免抢占蓝牙。按 macOS 提示允许运行程序使用蓝牙和本地网络。

## 安装和配对

下载[最新版本](https://github.com/BodenQ/laifen-homekit/releases/latest)并解压，在终端进入解压目录，运行：

```sh
python3 laifen.py setup
```

向导会让你选择安装模式，安装依赖，并扫描灯具。**只需设备名，不用填写蓝牙地址**；也可以直接回车，从扫描列表选择。设备名指 App 中类似 `LFFL01-P-ABCD` 的名称，不是家庭里自定义的「台灯」。首次联网下载依赖，之后在本地运行。

### 没有 Homebridge

1. 向导选「独立安装」，完成后运行 `python3 laifen.py run`。
2. 在 iPhone「家庭」→「添加配件」，扫描终端二维码；也可用终端配对码手动添加，并按提示继续添加未认证配件。查看配对码：`python3 laifen.py pair`。
3. 将四个控制项放在同一房间，按下表命名；上下灯若合并显示，可在配件设置中选择「作为单独版块分开显示」。
4. 测试整灯开关、两路独立开关、亮度和色温，观察真实灯光。确认正常后按 **Ctrl+C** 停止前台，再开启登录自启：

```sh
python3 laifen.py start
python3 laifen.py status
```

之后可关闭终端和 Codex。Mac **登录当前账号后**自动恢复；主动睡眠、退出登录或关机会中断控制。

### 已有 Homebridge

在现有 Homebridge 的**运行电脑、运行账号**下执行：

```sh
python3 laifen.py setup --mode existing
```

向导需要现有 `config.json` 路径和插件安装目录；会先备份配置，再合并本插件，保留原配对和其他配件。完成后，用原来的 Homebridge 管理器重启，**不必再添加一个桥接**。

要求 Homebridge 2.4.x；不知道路径时可以跳过自动合并，按[已有 Homebridge 安装说明](docs/existing-homebridge.md)操作。不会自动升级 Homebridge。Docker、不同服务账号等环境未实机验证。

## 日常使用

| 家庭中的名称 | 用途 / Siri 示例 |
| --- | --- |
| **台灯** | 整灯总开关：「打开台灯」「关闭台灯」控制两路 |
| **上灯** | 上灯独立开关、亮度：「关闭上灯」「上灯亮度调到百分之二十」 |
| **下灯** | 下灯独立开关、亮度；色温入口也在这里 |
| **自动亮度** | 开启或关闭灯内光线传感器调光 |

总开关独占「台灯」这个名称；若分控容器也叫「台灯」，改成「灯具分控」，避免 Siri 混淆。不要把自动亮度开关加入整灯开关群组。

- **色温是整灯共用的**，范围 2900–5700 K。调下灯的色温会同时改变上下灯。
- **Apple 自适应照明**调色温：在家庭的下灯颜色/色温页面选择自适应照明入口（家庭环境需支持）；手动选择色温会退出，需要时重新启用。
- **自动亮度**调亮度：使用灯内传感器。任一路关灯时暂停，两路都开后恢复；手动调亮度会退出，需重新打开该开关。关灯时开关可仍显示开启，代表保留偏好，不会自动把灯点亮。
- 全关后只开一路，另一边可能短暂亮一下；这是灯具需要先总开再分控的限制。
- 暂不提供落座感应、落座守护、定时或固件升级。

## 停止、更新和排错

以下命令在源码目录执行；使用自定义运行目录时，每条命令都加相同的 `--runtime`（见[维护说明](docs/usage.md)）。

| 要做什么 | 操作 |
| --- | --- |
| 暂停独立后台桥接 | `python3 laifen.py stop`（登录自启文件仍保留） |
| 恢复独立后台桥接 | `python3 laifen.py start` |
| 查看运行状态 | `python3 laifen.py status` |
| 前台查看错误 | 先停止后台，再执行 `python3 laifen.py run` |
| 更新 / 彻底停用 | 见[维护说明](docs/usage.md)；已有 Homebridge 用原管理器启停 |

找不到灯：确认灯通电、距离足够近、徕芬 App 已退出、没有第二个桥接占用，并检查 macOS 蓝牙权限。家庭显示无响应：检查 Mac 是否在线、桥接是否运行、局域网是否允许设备发现。配对异常时不要直接删除数据库，以免丢失原配对。

默认数据目录为 `~/Library/Application Support/LaifenHomeKitBridge/`。源码和运行数据分开保存；运行目录含配对信息，**请勿公开上传**。反馈问题可[创建 issue](https://github.com/BodenQ/laifen-homekit/issues)，说明灯型号、系统、运行版本、复现步骤，并删除日志中的地址、配对码和家庭信息。

换灯或换电脑需重新扫描、核对真实控制；新桥接通常需要重新配对。协议未观察到应用层设备密钥，但不能据此保证其他型号或固件通用。[兼容性与迁移](docs/compatibility.md) · [给 agent 的项目说明](AGENTS.md)
